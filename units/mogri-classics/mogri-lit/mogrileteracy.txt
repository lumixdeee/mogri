# mogrileteracy.txt

mogrileteracy (n.)

The deliberate retention of an apparent typo, slip, or error long enough to test whether the deviation carries a useful semantic direction.

It does not assume the deviation is meaningful.
The baseline remains available while the variant is explored under constraint.

A mogrileterate move:
- records the original form
- holds the deviation without silently correcting it
- asks what new relation or distinction, if any, the variant makes available
- permits falsification and return to baseline
- rejects literal enactment when the variant is only linguistic play

Outcomes:
- no useful distinction -> drop the variant
- repeatable semantic use -> retain it as a candidate term

Not the same as mogriliteracy, which describes apparent fluency that fails when context moves.

The joke may die.
The relation may remain.
